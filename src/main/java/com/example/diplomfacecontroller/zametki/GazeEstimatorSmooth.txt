Сглаживание координат взгляда
Для уменьшения влияния шумов и повышения стабильности управления курсором был реализован алгоритм экспоненциального сглаживания координат взгляда.
Сглаживание выполняется по формуле:

xₙ = α·x_raw + (1 − α)·xₙ₋₁
yₙ = α·y_raw + (1 − α)·yₙ₋₁

где α — коэффициент сглаживания. Это полностью соответствует твоему коду.
