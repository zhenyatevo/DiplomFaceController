# Мультимодальный интерфейс «взгляд-мимика»

Система компьютерного доступа для людей с выраженными двигательными нарушениями. Курсор позиционируется взглядом, команды подаются лицевыми жестами — всё через обычную веб-камеру, без специализированного оборудования.

## О проекте

Для людей с ДЦП, прогрессирующими мышечными дистрофиями, БАС, последствиями спинномозговых травм и инсультов клавиатура и мышь часто недоступны. При этом мимическая и глазодвигательная мускулатура у большинства остаётся сохранной даже на поздних стадиях — это делает движения глаз и лица естественным каналом управления.

Мультимодальный подход разводит позиционирование и активацию по независимым каналам: взгляд наводит курсор, мимика подтверждает действие. За счёт этого резко снижается число ложных срабатываний по сравнению с одноканальными системами (например, активацией по задержке взгляда).

## Возможности

- **Управление курсором взглядом** — оценка направления взгляда по ключевым точкам лица и радужки
- **Команды лицевыми жестами** — моргание (метрика EAR) и поднятие бровей с адаптивной базовой линией
- **9-точечная калибровка** под конкретного пользователя с оценкой качества
- **Каскадная фильтрация координат** — медианный фильтр против выбросов + адаптивное экспоненциальное сглаживание против дрожания
- **Экранная клавиатура** с доставкой символов в стороннее окно ОС через WinAPI `PostMessage`, без перехвата фокуса
- **Сбор телеметрии** — метрики кадров и дискретные события пишутся в единый CSV с общей временной осью

## Архитектура

Приложение построено по двухпроцессной схеме: нейросетевой инференс вынесен из основного процесса в отдельный Python-сервер, Java-клиент общается с ним по TCP.

```
┌──────────────────────────────┐        ┌───────────────────────────┐
│   Java-приложение (JavaFX)   │        │  Python: mediapipe_server │
│                              │  TCP   │                           │
│  захват видео (OpenCV)       │◄──────►│  MediaPipe Face Landmarker│
│  оценка взгляда              │        │  детекция ориентиров лица │
│  калибровка (МНК)            │        └───────────────────────────┘
│  детекция жестов (EAR/брови) │
│  фильтрация координат        │        ┌───────────────────────────┐
│  контроллер курсора          │───────►│  ОС Windows               │
│  экранная клавиатура         │        │  Robot / WinAPI PostMessage│
│  сбор метрик                 │        └───────────────────────────┘
└──────────────────────────────┘
```

Основные модули:

- `MainController` — главный контроллер приложения
- `GazeEstimator` — оценка направления взгляда
- `CalibrationManager` — калибровка и валидация коэффициентов
- `BrowRaiseDetector` — детекция поднятия бровей
- `KeyboardController` — виртуальная клавиатура
- `TextInjector` — доставка символов в активное окно ОС
- `IrisFeatureExtractor` — извлечение признаков радужки
- `MediaPipeClient` — TCP-клиент к Python-серверу
- `StatsLoggerUtils` — сбор метрик сессии

> Имена классов приведены по структуре проекта — поправьте под фактические, если они отличаются.

## Математическая основа

- **Калибровка** — метод наименьших квадратов, аффинная и проективная модели отображения координат взгляда в экранные
- **Сглаживание** — экспоненциальное сглаживание с адаптивным коэффициентом: сильное при малых смещениях (устойчивость курсора), слабое при резких (отзывчивость)
- **Нормализация** — линейная (min–max) и преобразования между системами координат камеры, кадра и экрана
- **Робастная фильтрация** — одномерный медианный фильтр для подавления выбросов

## Требования

- Windows (интеграция с ОС использует WinAPI)
- JDK 17+ и Maven (в репозитории есть Maven Wrapper — отдельная установка не нужна)
- Python 3.9+
- Веб-камера

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/zhenyatevo/<repo>.git
cd <repo>

# 2. Создать окружение для Python-сервера и поставить зависимости
python -m venv mediapipe_env
mediapipe_env\Scripts\activate
pip install mediapipe opencv-python numpy

# 3. Запустить сервер MediaPipe
python mediapipe_server.py

# 4. В отдельном терминале — собрать и запустить Java-приложение
mvnw.cmd clean javafx:run
```

Модель `face_landmarker.task` лежит в корне репозитория и подхватывается сервером при старте.

## Использование

1. Запустите Python-сервер, затем основное приложение.
2. Пройдите калибровку: последовательно фиксируйте взгляд на девяти точках. Приложение покажет оценку качества — при низкой лучше повторить.
3. Курсор следует за взглядом. Поднятие бровей активирует выбранный элемент.
4. Для ввода текста откройте экранную клавиатуру: наведите взгляд на клавишу и подтвердите жестом. Символ уйдёт в окно, которое было активным.

Калибровка индивидуальна и привязана к положению головы и освещению — при смене пользователя или заметном изменении условий её нужно повторить.

## Результаты тестирования

Проведено 7 сессий общей длительностью 31 минута по четырём группам сценариев: тип нагрузки, внешние условия, воспроизводимость и длительная сессия. Участвовали два человека, что позволило оценить переносимость системы между пользователями после повторной калибровки.

| Метрика | Результат | Порог |
|---|---|---|
| Медианный FPS | 29.3 | ≥ 25.0 |
| Детекция лица | 100% | — |
| Доля доставленных символов | 100% | — |
| Скорость ввода | 1–2 симв./мин | — |

Детекция лица сохранила 100% во всех сценариях, включая ослабленное освещение и смену пользователя. Достигнутая скорость ввода соответствует типичному диапазону систем альтернативного управления без использования рук.

## Структура репозитория

```
├── src/                      # исходники Java-приложения
├── mediapipe_server.py       # Python-сервер детекции лицевых ориентиров

├── summary_analysis.ipynb    # сводный анализ по всем сессиям
├── figures/                  # графики, построенные ноутбуками
├── report_assets/            # материалы для отчёта
├── lab_journal.xlsx          # лабораторный журнал тестовых сессий

```

## Анализ метрик

Логи сессий пишутся в CSV в `stats/` с единой временной осью, так что дискретные события сопоставимы с состоянием системы в тот же момент. `analysis.ipynb` разбирает отдельную сессию, `summary_analysis.ipynb` за один проход по всем сессиям строит сводную таблицу метрик и обзорный график ключевых показателей; графики сохраняются в `figures/`.
